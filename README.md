# ShowUserspaceSpawnButton

A [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader) mod for [Resonite](https://resonite.com/) that shows the userspace spawn button on any item regardless on if its a facet.

remember that anything you spawn in your userspace can touch anything you can. to list some things you can touch in userspace: desktop, file system. be careful!

## Installation
1. Install [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader).
1. Place [ShowUserspaceSpawnButton.dll](https://github.com/fpgagay/NeosShowUserspaceSpawnButtonRML/releases/latest/download/ShowUserspaceSpawnButton.dll) into your `rml_mods` folder. This folder should be at `C:\Program Files (x86)\Steam\steamapps\common\Resonite\rml_mods` for a default install.
